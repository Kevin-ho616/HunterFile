# HunterFile 使用说明

HunterFile 是原生 macOS 素材管理器。首次启动会在 `~/Pictures/HunterFile/我的资源库.openeagle` 建立独立资源库。可以在左上角菜单新建或切换资源库，也可以体验内置的独立示例库。

## 日常使用

1. **导入**：⌘I 选择文件/目录，或从 Finder 拖到中央区域。目录结构会转为逻辑文件夹。原文件保留；按内容去重，并合并分类与标签。
2. **整理**：右栏可改名称、备注、来源、标签、评分、收藏。素材从 A 文件夹拖入 B 文件夹会移动，移除 A 中的归属，可用 ⌘Z 撤销；使用“添加到文件夹”可保留多重归属。文件夹拖到行间的插入线可调整顺序；拖到名称上高亮后松开，会成为该文件夹的子文件夹；拖到顶层文件夹之间或列表末尾可移回顶层。悬停在有子文件夹的目标上会自动展开，顺序和层级自动保存。右键“调整位置”也可上移、下移或移到顶层。文件夹右键可分别“新建同级文件夹”或“新建子文件夹”；同级沿用当前文件夹的上级，子级放入当前文件夹。“整理 → 新建文件夹”（⌘⌥N）默认新建同级，未选文件夹时建在顶层；侧栏“文件夹”标题旁的 ＋ 始终新建顶层文件夹。新建窗口中可通过“上级文件夹”确认或调整位置。文件夹右键还可编辑、设置自动标签。编辑文件夹 → “选择图标”打开内置 80 个图标的图标库，支持中文/英文关键词搜索与分类筛选，涵盖常用、设计创作、工作项目、图片分类、内容媒体、生活旅行；选好后点击“保存”。图标可搭配颜色或恢复默认，随资源库备份和素材包一起保存。
3. **浏览与搜索**：在网格或瀑布流的素材区域按住 ⌥ Option，向上滚轮放大缩略图、向下缩小，与底部大小滑块同步并记住设置；松开 Option 后正常滚动。⌘F 搜名称、标签、备注、来源、OCR 与标注。空格分开的关键词全部匹配。筛选按钮提供类型、颜色类别、评分、尺寸、比例、大小与日期筛选，可保存成智能文件夹。
4. **预览**：单击立即选中，双击或空格直接在主窗口的素材区域打开，保留侧栏与属性面板；左右箭头切换，Esc 或“返回素材”回到原列表位置。图片可缩放与标注；在图片画布内向上滚轮放大、向下缩小，范围为 25%–400%，与工具栏滑块同步，点击百分比恢复 100%。标注模式暂停滚轮缩放。视频/音频使用原生播放器，PDF 使用 PDFKit，字体可输入预览文字。其他格式交给系统 Quick Look。缩略图右下角有放大镜，点击可直接进入详情。设置中开启“悬停放大镜 0.5 秒后预览”后，只有在放大镜区域停留半秒才显示放大框，移到缩略图其他位置即收起。网格和瀑布流共用固定在素材区域中央的放大框，随区域大小尽量铺满、保持素材完整比例。点击、切换选择、框选或拖拽时取消悬停预览，鼠标移出放大镜后重新停留才会再次触发。
5. **批处理**：网格和瀑布流中，从空白处按住鼠标左键拖动可框选当前可见的素材，选框碰到卡片即选中；⌘/⇧ + 框选可追加选择，Esc 取消本次框选，点击空白处清空选择。从卡片上起拖仍用于移动文件。也可用 ⌘/⇧ 点击多选，右栏批量标签/评分/分类。素材菜单可批量重命名、OCR、自动分类或导出。⌘Z 撤销素材编辑。
6. **导出**：⌘E 导出原件与可选 JSON 元数据、可重新导入的 `.openeaglepack` 素材包，或转换静态位图到 PNG/JPEG/TIFF、缩放或顺时针旋转。重名文件自动编号。文件夹右键可导出全部下级素材。
7. **回收站**：⌘⌫ 将所选素材移入应用内回收站；可以恢复。清空时会把原件和元数据移入 macOS 废纸篓。

## 母文件夹与子文件夹

- 默认只显示当前文件夹直属的素材；子文件夹作为独立入口显示在上方，点击进入后可用“上级文件夹”返回。
- 勾选“包含子文件夹内容”后，浏览、搜索和侧栏计数包含全部下级素材，同一素材只计算一次。选项会记住，并统一应用于文件夹浏览。
- 文件夹右侧的数字是素材总数，不包含文件夹数量，也不随搜索筛选变化。没有直属素材时显示 0；“子文件夹 · N”单独表示子文件夹数量。搜索后页面显示“匹配素材”数量。
- 默认从母文件夹移出素材，只移除其直属归属，不改动已有的子文件夹归属；开启包含子文件夹后，移动才会处理当前列表中的下级归属。移动到当前母文件夹的子级后，若开关开启，该素材仍会出现在母文件夹的汇总列表中。
- 一个素材可属于多个分类，所以不同文件夹的数字不能简单相加当作全库素材数。右键“导出文件夹及子文件夹中的素材”明确导出整棵目录的素材。

## 资源库与迁移

- 资源库包含 `library.json`、`library.sqlite`、`assets/`。素材以 UUID 命名的目录存放，显示名称与存储文件名分离。
- SQLite 事务与文件原子移动保护导入过程；多个应用进程不能同时打开同一资源库。
- “文件 → 导入 Eagle 资源库”只读取 `.library`，复制可识别的原件，并迁移文件夹层级、标签、备注、来源、星级和添加时间；不会修改源库。
- Eagle 的私有插件、智能文件夹内部规则、密码状态和时间轴标注不会在迁移时转换。缺失文件会逐项记录；请看任务记录。
- 使用“备份完整资源库”生成一致的可重开备份。关闭应用后可用外置盘或同步工具复制整个资源库。**不支持多设备同时写同一个库**。
- 外置磁盘离线、数据库缺失或损坏会报错，应用不会用空数据库替换已有素材。
- 素材包保存原件、文件夹层级、标签、评分、备注与图片标注；可通过“导入素材”选择整个 `.openeaglepack` 包导入其他资源库。它是 HunterFile 自身格式，不兼容 Eagle 官方素材包；分享时不会复制文件夹密码。

## 文件夹保护

文件夹右键 → 编辑文件夹，可设置至少 6 位密码。选择“锁定”后，下级素材也会从浏览、搜索和本地接口中隐藏；重启后需要重新解锁。未保存编辑需要先保存，再锁定或切换资源库。

密码采用随机盐与 PBKDF2 摘要保存。**这是应用内访问保护，不是文件加密**：原件仍可通过 Finder 读取，也会包含在完整备份中。忘记密码没有应用内重置通道，请妥善保管。

## 浏览器采集

1. HunterFile → 设置 → 扩展 → 启用本地采集 API。
2. 点击“复制采集令牌”。
3. 打开扩展文件夹，在 Chrome / Edge 扩展管理页启用开发者模式，选择“加载已解压的扩展”。
4. 在扩展设置粘贴令牌并测试连接。
5. 点击扩展按钮，可按最小宽度筛选页面图片，批量采集、保存书签或截取当前可见页面；右键图片也可保存。

采集服务只监听 `127.0.0.1:41596`，除健康检查外均需要令牌。当前扩展提供可见区域截图；不包含 Eagle 官方的站点专用高清提取规则、Safari 原生扩展与滚动长截图。

## 本地智能功能与 AI

- 选中图片后，“素材 → 识别文字（本地）”使用 Apple Vision；PDF 提取可选中文字。识别结果显示在右栏并可搜索、复制。
- “自动分类标签（本地）”生成 Apple Vision 的英文分类标签，可以手动合并或重命名。
- 设置 → AI → 下载 EmbeddingGemma 2 文字与视觉 440M 模型，再“选择模型”。开启本地 AI 后，后台为可见素材建立索引，支持暂停、继续与重新建立；新增素材和名称、标签、备注修改会增量更新。模型校验失败或缺失时保留关键词搜索。
- 搜索框旁的「AI 搜索」独立开关切换本地 AI 搜索，蓝色开启、灰色关闭；未配置模型时会打开选择窗口，取消后保留原状态。开启后可用中文描述内容，图片按钮支持以图搜索。窄窗口会将标题和搜索控件分为两行。“查找相似图片”在本地 AI 启用时使用相同索引，可发现相关 PDF 和视频；关闭后仍使用 Apple Vision 比较前 100 项图片。
- 检索按相关度排列，关键词直接命中优先，最多显示 500 项。筛选器、文件夹范围、锁定与回收站规则继续生效。结果上的页码和时间对应匹配内容，打开预览会定位到该页或时刻。
- “AI 整理 → 本地分类”根据已有标签、文件夹说明和示例素材提出候选，标签可编辑，文件夹可取消勾选；应用只追加分类，保留名称与备注，支持 ⌘Z / ⇧⌘Z。候选相似度不是概率，需要人工判断。
- 设置 → AI 中填写兼容 Chat Completions 的**完整视觉接口地址**、模型名和 API Key。密钥保存在 macOS 钥匙串。
- “AI 整理 → 接口生成”只有点击生成后才发送所选素材的缩略图和名称。建议可预览、修改，再应用；支持名称、标签、备注。
- 智能文件夹可勾选“按语义描述收集素材”，输入主题并设定相关度门槛，同时保留类型、标签等规则。语义归属只来自已索引素材；关闭本地 AI 时需要重新启用才能查看。
- 设置 → AI → 下载并选择 Gemma 4 E2B 生成模型。“AI 整理 → 本地生成”逐项预览名称和 AI 摘要，勾选要应用的素材；默认保留原名称，只有勾选“应用名称”才覆盖显示名称。AI 摘要独立保存，人工备注保留；支持撤销、重做。
- 素材菜单 → 素材问答，依据当前范围的检索片段与画面在本机回答，点击来源核对 PDF 页码或视频时刻。长文档与视频仅作抽样分析，音频未转写，证据不足会提示。
- 两种本地模型均由用户下载，项目不附带付费模型服务。支持格式、覆盖限制和受控评测见 [本地 AI](LOCAL-AI.md)。

## 自动导入与插件

“整理 → 自动导入文件夹”每 10 秒检查已启用目录，应用需要保持运行。复制中的文件至少静置 5 秒后处理；已处理签名保存在资源库中。取消任务会停止后续文件，当前文件复制完成后响应取消。

设置 → 扩展可打开内置“素材统计与清单导出”插件，或打开包含 `plugin.json` 的本地 HTML 插件。插件 API：

```javascript
const assets = await hunterfile.getSelection();
const library = await hunterfile.getLibrary();
await hunterfile.saveText('notes.txt', '由用户选择保存位置');
```

插件接口是 HunterFile 自身协议，并非 Eagle 的 Node.js/HTML 插件 API。只加载你信任的插件。

## 当前边界

任何普通文件都能存储与分类；预览能力依赖本机系统解码器与 Quick Look 扩展。不能保证每一种 RAW、3D、Adobe 工程、视频编码和 Web 字体均可在应用内完整预览。图片颜色是量化的颜色类别；不是专业色彩测量结果。

图片预览为控制内存最多解码 4096 像素的最长边，缩略图为 640 像素。原件保持完整，可在默认应用中打开；原件导出不会降低分辨率。格式转换支持最多 1.6 亿输出像素，较大的文件需指定缩小尺寸。

当前未提供原件加密、音频 BPM 分析、Eagle Marketplace 兼容、Pinterest 跨来源检索、AI 擦除/背景移除/超分辨率、团队协同或云冲突合并。这些与当前可使用的素材管理功能分开记录，不声称已达到 Eagle 全量功能等价。

本地应用使用 ad-hoc 签名。面向其他用户分发时需要 Apple Developer ID 签名与公证。
