# OpenEagle 验收记录

日期：2026-09-12。验证环境：本机 Apple Silicon、macOS 26.6.2、Swift 6.3.3。源码最低目标 macOS 14；未在 macOS 14 或 Intel 实机测试。无第三方运行库。

## 可重复运行的检查

```sh
swift test
./script/build_and_run.sh --verify
```

自动化测试包含 31 个测试函数，覆盖复制导入与 SHA-256 原件一致性、重开与备份、重复导入/合并、回收站恢复、文件夹层级/自动标签/智能规则、字面搜索、路径逃逸/重复打开/不覆盖导出、Eagle 迁移样本、锁定文件夹的查询隔离、失败批处理回滚、中断导入恢复、素材包跨库往返、并发编辑、25,000 条模拟索引、位图尺寸/顺时针旋转、原生预览视图更换、元数据草稿合并、本地 OCR 识别，以及文件夹图标的旧格式兼容与重置、80 个图标的可渲染性和分类搜索。文件夹移动检查覆盖同级排序、跨层级移动、拒绝自身及后代作为目标、锁定保护、重命名后保持顺序、重开/备份/素材包保存顺序与层级，以及素材归属和原件完整性；拖放解析检查区分内部素材 ID 与外部文件，避免把内部原件再次导入。预览检查覆盖 Quick Look 放大层在两种窗口尺寸下的居中铺满与鼠标穿透、内嵌预览的选择保留和分类切换退出，以及滚轮缩放方向、精确滚动增量、单次幅度与 25%–400% 边界。原生鼠标事件回归：单击后 50 毫秒内选中并收起已有悬停预览，第二次点击仍打开内嵌详情；旧实现会在前两项断言失败。缩略图快捷缩放检查使用原生窗口中的主视图和带 Option 标记的测试滚轮事件，验证网格/瀑布流内增减、120–340 边界、普通滚动与侧栏区域放行、详情预览禁用和列表模式移除接收器。侧栏回归在原生窗口中检查父级、子级及同级文件夹切换后只有当前分类保持选中，并通过窗口鼠标事件验证点击空白处清理残留拖放反馈，选择素材也会清理反馈。原生文件夹拖动检查保留点击响应、微小移动后松手的取消行为，以及含中文和空格的资源库路径与文件夹 ID 的传输一致性。新增放大镜入口回归：在原生窗口中点击缩略图右下角按钮，验证选中对应素材、进入内嵌详情并收起已有悬停层。同级新建回归覆盖顶层、子级、孙级、无选中文件夹，以及右键目标与当前分类不同的父级解析。单个测试函数可能覆盖多项行为。

25,000 条模拟元数据在本机 debug 构建下：默认 500 项分页、1,000 项组合搜索、500 个 ID 批量读取，合计约 **0.25 秒**。这是索引检查；没有用这项结果推断 25,000 张图片的导入时间、缩略图浏览帧率或百万级素材表现。

测试 API 与 MCP 使用独立的 QA 应用、偏好与资源库：

```sh
./script/build_and_run.sh --qa
# 在 OpenEagleQA 的设置中启用本地 API，再执行：
python3 script/verify_api.py
```

该脚本先核对监听进程确实为 `OpenEagleQA`，才允许写入测试素材。实测通过：401 认证拒绝、文件夹创建、PNG 截图、带缩略图的书签、非法评分回滚、元数据更新与含空格搜索、本地路径拒绝、CLI 绕过系统网页代理、MCP 初始化/工具列表/真实搜索。令牌不写入测试报告。

## 本机原生界面实测

在独立测试库中完成：

- 网格和瀑布流中，从空白处反向拖动跨过两个素材，实测标题显示“已选 2 项”、两个卡片高亮、右侧进入批量编辑；空白点击清空选择。原生窗口回归检查使用真实布局的卡片边界，覆盖部分相交命中、缩小选框移除旧命中、⌘/⇧ 追加、Esc 恢复原选择、关闭接收器后事件放行，以及卡片起拖事件不被框选接收器截获。框选范围为当前可见区域，未实现拖至边缘自动滚动。

- 母文件夹默认显示 7 个直属素材，上方显示 1 个子文件夹入口；开启“包含子文件夹内容”后页面与侧栏同时为 9 项。搜索子级名称时，开启显示 2 个结果、关闭为 0；侧栏仍显示未筛选总数。点击子文件夹入口显示其 2 项素材，“上级文件夹”返回 7 项；重启后开关保持开启，再关闭恢复 7 项。测试结束恢复默认选项与临时层级。自动化回归覆盖多层目录、只有子文件夹的空母目录、重复归属去重、回收站/锁定素材排除、分页总数与查询 ID 一致，以及两种范围下移动与撤销。新增目录入口的实际拖放落点本轮未验证成功，不计为已通过的界面检查。

- 图片从 A 文件夹拖到 B，A 从 2 项变为 1 项、B 从 1 项变为 2 项，源列表移除该图片、目标列表出现该图片；另一份独立分类归属保留，总素材仍为 12 项，逐一校验全部原件 SHA-256 未变。⌘Z 后 A/B 数量及归属恢复。新增回归检查同时覆盖批量移动、来源父级中的子级素材、目标已包含同一素材、同文件夹空操作、目标不存在或锁定时不修改数据、自动标签、撤销/重做数据与重开持久化。
- 素材单击与双击同时识别：坐标单击的选中回调距鼠标事件约 9 毫秒，坐标双击正常打开内嵌详情。测量使用的临时 QA 日志已移除。

- 导入目录中的 PDF、字体、WAV 与 H.264 MOV，目录转换为逻辑文件夹；重复字体按内容跳过。
- 网格、列表、搜索、选中素材、右栏标签与五星评分，重启后重新读回。
- 缩略图大小滑块显示“⌥ Option + 滚轮”提示；调节大小后网格与瀑布流重新排布，普通滚轮仍可浏览且不改变缩略图大小。Option 组合键的事件路由由上面的原生窗口测试验证，界面自动化工具不支持持续按住修饰键滚动。
- 图片实际预览、拖动区域标注、保存标注、按标注文字搜索。
- 图片与书签在主窗口素材区域内预览，侧栏和属性面板保持可用；方向键切换、属性输入框内的光标移动、Esc 与“返回素材”均已实测。列表滚动到底部后打开预览，返回时仍停留在底部并保留选择；切换类型分类退出预览。
- 图片画布内向上滚动从 100% 放大到 146%，向下滚动回到 100%，滑块与百分比同步；属性面板内滚动和标注模式下滚动不改变缩放值。退出预览后，素材列表滚动正常。
- 2026-09-12：独立 QA 库实际创建顶层同级文件夹，再创建 Child A 和它的同级 Child B；界面和数据库读回均确认二者同属 QA Sibling 0912。发现并修复嵌套右键菜单误用父级目标的问题，菜单改为绑定单行；重新验证右键和 ⌘⌥N 的上级预设正确。测试库保留这组三个空文件夹供后续层级回归。
- 2026-09-10：QA 应用确认图片缩略图右下角常驻放大镜，点击后在主窗口打开详情；视频瀑布流中时长与放大镜并排且不重叠。设置文案更新为“悬停放大镜 0.5 秒后预览”。悬停触发区域和取消路径已检查源码；当前 UI 工具无法可靠模拟连续悬停，未实测半秒触发与提前移出的时序。
- 网格和瀑布流中，放大层固定在素材区域中央，切换不同列的图片时位置不变；显示放大层后，坐标双击仍进入内嵌详情。此次通过临时 QA 动作触发展示与收起，完成检查后移除动作；自动化工具未直接验证连续鼠标悬停的 0.8 秒触发。
- 拖入状态线改用滚动视口外的固定留白，光晕限制在边缘内。通过 QA 临时显示状态线，检查网格和瀑布流在顶部、滚动中途及底部的间距，线条与光晕不覆盖缩略图；检查后恢复仅拖入时显示。
- 移入应用回收站、列表消失、回收站保留评分与元数据、恢复后重新出现。
- PDFKit 显示真实 PDF 内容，CoreText 显示无需安装的字体及可编辑预览文字。
- H.264 视频实际播放，画面和播放进度发生变化；有效 WAV 文件显示 2 秒时长，静音播放时进度推进。
- 文件夹图标库按“工作项目”筛选、搜索“摄影”、选择相机图标并保存，侧栏立即更新；重启后读回相机图标，筛选文件夹时也显示正确。改选项目图标后取消编辑，原相机图标保持不变。
- 针对多行蓝色选中残影，使用同一测试文件夹做实际鼠标拖动对照：原实现从一个父级移入原本没有子级的文件夹后，点击“全部素材”仍留下蓝色行，但辅助功能仅报告一个选中项。改为 AppKit 发起拖动后，反复跨父级移动、目标从叶子变为父级，再切换到父级或全部素材，旧行背景均消失；右键菜单和键盘向上切换正常。原生列表插入回调可接收新的拖动载荷；本轮没有完成边界间隙全部落点的界面回归。临时诊断代码已移除，QA 文件夹元数据恢复原状。
- 侧栏子文件夹点击后进入对应内容，再点击“全部素材”，原文件夹底色与拖放描边消失；仅当前分类保持选中。测试临时构造的子级关系已恢复。
- 文件夹拖入另一文件夹、根目录与子级同级排序、连同子树移动、子文件夹拖回顶层及列表末尾，重启后顺序和层级保持。向折叠的父文件夹放下后会展开并显示新子文件夹；自动化工具未直接测量连续悬停 0.65 秒展开。未分类图片拖到文件夹后，未分类数量从 1 变为 0、目标文件夹从 1 变为 2，撤销后恢复原分类；测试库文件夹也恢复到原顺序和层级。

实测中修复了 Quick Look 生命周期崩溃、SwiftUI VideoPlayer 在本机运行库中的崩溃、CLI 本机连接被网页代理接管、API 查询参数中的空格编码、位图旋转以及异步编辑覆盖风险。播放器使用 AppKit `AVPlayerView`。预览视图更换和草稿字段合并留有自动化回归检查。

## 数据边界

测试库位于项目 `test-output/`。示例库位于 `~/Pictures/OpenEagle/示例素材库.openeagle`，由应用单独生成。没有对现有 Eagle 私人资源库做整库迁移、覆盖或删除。

迁移测试验证的是构造的 Eagle 元数据/原件样本，不能代替对所有历史 Eagle 版本的兼容性测试。应用逐项报告无法迁移的文件。原件导入与素材包往返测试比较了 SHA-256；显示名称和注释修改不会改写原始文件。

## 安装与打包

优化构建已安装到 `~/Applications/OpenEagle.app`，并从安装位置打开、确认资源库读取正常。应用约 6 MB，签名验证 `codesign --verify --deep --strict` 与 Info.plist 校验通过。侧栏“字体”已按反馈替换为独立的书本图标，普通文件夹支持从内置图标库选择图标。

## 尚未完成的外部验证与功能差异

- 未配置真实远程模型密钥，所以外部 AI 整理接口尚未完成真实提供方的端到端调用。界面需要用户填写接口、模型与密钥，再明确触发上传。
- Chrome/Edge 扩展已交付源文件，并通过 JavaScript 语法检查与真实本机 API 载荷检查；未代用户安装浏览器扩展，也未覆盖所有网站的 DOM 与反下载策略。
- 屏幕区域截图需要 macOS 权限，没有自动授予或代用户进行屏幕录制测试。
- Quick Look 预览依赖系统及本机格式扩展；没有逐一验证 Eagle 宣传的所有格式。
- 不兼容 Eagle 官方 Marketplace 插件或官方 eaglepack 协议；没有完整云端语义模型、Pinterest 联动、音频 BPM、AI 擦除/超分/背景移除、团队协同与同步冲突合并。
- 文件夹密码用于应用内访问保护，原件没有加密。
- 发布物为本机 Apple Silicon 构建与 ad-hoc 签名；没有 Developer ID 签名和 Apple 公证，未声称面向任意外部 Mac 的发行验证已完成。
